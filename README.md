# 🔗 Python URL Shortener

A simple **Flask-based URL Shortener** that converts long URLs into short links and tracks how many times each link is visited.
The application stores data using **SQLite** and provides a small dashboard to view, manage, and delete shortened URLs.

---

## ✨ Features

* Generate short URLs for long links
* Redirect to original URLs
* Track visit counts
* View all shortened URLs
* Delete URLs
* Lightweight SQLite database

---

## 🛠 Tech Stack

| Technology  | Purpose             |
| ----------- | ------------------- |
| Python      | Backend programming |
| Flask       | Web framework       |
| SQLite      | Database storage    |
| HTML        | Web page structure  |
| TailwindCSS | UI styling          |

---

## ▶️ Run the Project
